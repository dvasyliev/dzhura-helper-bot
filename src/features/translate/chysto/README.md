# chysto data

Vendored from https://github.com/vladichumachenko/chysto-ukr-skills (path `skills/chysto/data/`), fetched 2026-11-25.

- `lt-replace.tsv`: russianisms and barbarisms from LanguageTool; only rows with level `error` are used.
- `chysto-calques.tsv`: calques of Russian phrases; all rows are used.
